# История изменений

Все заметные изменения Stack Manager собраны в этом файле.

## [1.0.9] — 2026-10-18

### Документация и релизы

- Добавлен полноценный `CHANGELOG.md` с историей версий.
- Для тегов `v1.0.3`–`v1.0.7` опубликованы недостающие GitHub Releases.
- Workflow релизов теперь берёт описание версии из `CHANGELOG.md`.
- В релизный архив включается `CHANGELOG.md`.
- Документация CDN в README приведена в соответствие с реальной схемой XHTTP.

## [1.0.8] — 2026-10-18

### Исправлено

- Синхронизирована версия в `VERSION` с тегом релиза `v1.0.8`.
- Исправлена публикация релизного пакета и SHA256-файла.
- В релизный архив включаются актуальные скрипты, README и assets.

## [1.0.7] — 2026-10-18

### Исправлено

- Исправлен сдвиг автоответов в первичной настройке.
- Восстановлена корректная привязка ответов к вопросам мастера настройки.

## [1.0.6] — 2026-10-18

### Изменено

- Возвращены Unicode-флаги стран в названия инбаундов.
- Названия снова отображаются в формате вроде `🇸🇪`, а не `SE`.

## [1.0.5] — 2026-10-18

### Исправлено

- Добавлена миграция повреждённых названий существующих инбаундов.
- Исправлены старые `remark`, в которых страна отображалась некорректно.

## [1.0.4] — 2026-10-18

### Исправлено

- Исправлено отображение страны в `remark` новых инбаундов.
- Подготовлена корректная генерация названий для панели.

## [1.0.3] — 2026-10-18

### Изменено

- Зафиксирован отдельный релиз с накопленными исправлениями после `v1.0.0`.
- Продолжена стабилизация логики именования инбаундов и отображения страны.

## [1.0.2] — не выпускалась

Версия не имеет отдельного Git-тега или опубликованного GitHub Release. Номер пропущен, чтобы не создавать фиктивный релиз задним числом.

## [1.0.1] — не выпускалась

Версия не имеет отдельного Git-тега или опубликованного GitHub Release. Номер пропущен, чтобы не создавать фиктивный релиз задним числом.

## [1.0.0] — 2026-10-17

### Добавлено

- Безопасное автообновление скрипта через GitHub Releases.
- Версионированный релизный пакет.
- Резервный помощник для отката.
- SNI-маршрутизация, Reality, XHTTP/CDN, decoy, сертификаты и диагностика стека.

### Документация

- Добавлены русские архитектурные схемы и обновлён README.
