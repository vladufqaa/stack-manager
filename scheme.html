UFW — активен
ALLOW: 22/tcp (SSH) · 443/tcp (весь стек) · UDP-порты туннелей  |   DENY: 80/tcp · порты панели и подписок · 46002 (web csqtt)  |   default: DENY всё остальное. 53/323/6010–6019 не открываются никогда.
▼  только разрешённый трафик  ▼

nginx :443 — SNI-роутер (ssl_preread, TLS не терминирует, разделение по server_name)

SNI = домен панели панель

nginx 127.0.0.1:4443 — TLS-терминация (wildcard)
/секретный путь/ → x-ui панель 127.0.0.1:<webPort>
/subPath/ → sub-сервер 127.0.0.1:<subPort> (subURI = https://…:443)
/ (корень) → decoy-заглушка «обычный сайт»
опция: прокси на AdGuard UI + DoH /dns-query

SNI = домен Reality reality

xray vless+reality 127.0.0.1:<порт>
свой клиент (верные ключи) → прокси-туннель

чужое рукопожатие → dest 127.0.0.1:4444 = decoy-сайт (единственный decoy для инбаундов)

SNI = домены TLS-инбаундов tls

naive / anytls / trusttunnel 127.0.0.1:<порт>
nginx 443 передаёт ClientHello напрямую инбаунду (passthrough)
серт отдаёт сам инбаунд (wildcard)
decoy не создаётся

udp UDP-туннели — мимо nginx (QUIC не проходит через 443/tcp)

hysteria2 :<порт>/udp
qwdtt :56000/udp + wg :56001/udp + raw :56003/udp
csqtt :46000/udp (web 46002/tcp — DENY, только localhost)

stack-manager.sh — что чем управляет

п.1 Первичная настройка
sni-router.conf (map SNI→upstream) · stack.conf (панель+decoy) · x-ui.db (порты/пути/subURI/hosts) · decoy только: панель + Reality · вопрос про UFW
п.2 Инбаунды
рецепты: vless-reality, naive, anytls, trusttunnel, hysteria2, qwdtt, csqtt → БД + SNI-маршрут + hosts + креды
п.4 Смена decoy
выбор домена списком (только существующие decoy: Reality + панель)
п.10 Сертификаты
certbot wildcard DNS-01 через Cloudflare API — один сертификат на все поддомены, 80/tcp не участвует
п.11 Файрвол
UFW по фактическим listen-портам; loopback/53/323/6010-19/46002 — никогда наружу
п.13/14 Установка
LucX-панель (неинтерактивно, домен+серт сразу) · AdGuard Home (опция: UI+DoH по https на localhost, наружу через 443)
